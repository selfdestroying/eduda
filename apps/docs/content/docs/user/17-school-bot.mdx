### Для чего нужен раздел

Напоминания о занятиях приходят родителям в MAX. По умолчанию их отправляет бот ЕДУДА. Школа может подключить собственного бота — тогда родители видят в чате название и логотип школы, а не ЕДУДА.

### Кто может пользоваться

Подключать бота и переключаться между ботами может только владелец школы. Менеджер видит, какой бот сейчас работает, но изменить выбор не может.

### Что понадобится

- Подтверждённый профиль организации, ИП или самозанятого на платформе MAX для партнёров — [business.max.ru](https://business.max.ru/self). Без него создать бота нельзя.
- Свободный слот под бота: организация или ИП могут создать до 5 ботов, самозанятый — до 2.
- До 48 рабочих часов на модерацию бота в MAX.
- Бот, который будет работать только с ЕДУДА. Если бот школы уже подключён к CRM, чат-виджету или другому сервису, создайте для ЕДУДА отдельного.

### Шаг 1. Создайте бота на платформе MAX для партнёров

1. Откройте свой профиль на [business.max.ru/self](https://business.max.ru/self).
2. В разделе "Чат-боты" нажмите "Создать".
3. Заполните карточку бота:
   - **"Логотип"** — квадратная картинка 500×500 пикселей, JPG или PNG, до 5 МБ. Родители увидят её как аватар бота.
   - **"Название чат-бота"** — от 1 до 59 символов: латиница, кириллица, цифры. Это имя родители увидят в чате — обычно название школы.
   - **"Никнейм"** — создаётся автоматически, вида `idИНН_bot`, и сейчас не меняется. По нему ЕДУДА собирает ссылку на бота.
   - **"Описание"** — до 200 символов о том, что делает бот. Например: «Напоминаем о занятиях и открываем личный кабинет родителя».
4. Нажмите "Создать". Бот уйдёт на модерацию.

{/* Скриншот: /images/school-bot/01-create-bot.png — карточка создания бота на платформе MAX для партнёров */}

Статусы модерации:

- **"На модерации"** — настройки бота менять нельзя. Обычно до 48 рабочих часов.
- **"Опубликован"** — бот прошёл модерацию, можно переходить к следующему шагу.
- **"Нужны исправления"** — поправьте карточку по замечаниям и отправьте снова.

### Шаг 2. Привяжите кабинет родителя к боту

Мини-приложение — это кнопка в чате с ботом, по которой родитель открывает свой личный кабинет прямо в MAX: расписание, посещаемость и оплаты.

1. На платформе MAX для партнёров откройте "Чат-боты" и нажмите "Перейти".
2. У своего бота нажмите "⋮" → "Настройки".
3. В поле адреса мини-приложения вставьте адрес:

   ```
   https://parent.eduda.online/max
   ```

4. Выберите тип кнопки.
5. Нажмите "Сохранить".

{/* Скриншот: /images/school-bot/02-mini-app.png — настройки бота с адресом мини-приложения */}

Что важно:

- Вставляйте адрес целиком, без пробелов. MAX принимает только адреса, начинающиеся с `https://`.
- Без этого шага напоминания работают, но родитель не сможет открыть кабинет из чата с ботом. При подключении в ЕДУДА пропущенный шаг не заметен — выяснится, только когда родитель нажмёт кнопку.

### Шаг 3. Скопируйте токен бота

Токен — это ключ, по которому ЕДУДА пишет родителям от имени бота. Он появляется в настройках бота на платформе MAX для партнёров, когда бот прошёл модерацию.

{/* Скриншот: /images/school-bot/03-token.png — где на платформе MAX для партнёров лежит токен бота */}

Что важно:

- Токен даёт полное управление ботом. Не пересылайте его в мессенджерах и почте — сразу вставьте в ЕДУДА.
- После сохранения в ЕДУДА токен больше не показывается никому — ни владельцу, ни менеджеру.

### Шаг 4. Подключите бота в ЕДУДА

1. Откройте раздел "Боты".
2. В блоке "Настройка" выберите "Свой бот". Ниже появится поле для токена. Пока бот не сохранён, у варианта стоит бейдж "Не сохранён", а напоминания по-прежнему отправляет бот ЕДУДА.
3. Вставьте токен в поле "Токен бота" и нажмите "Тест". ЕДУДА проверит токен в MAX и покажет название и аватар бота — убедитесь, что это ваш бот.
4. Нажмите "Сохранить". Кнопка становится активной только после успешного "Теста": если поменять токен в поле, проверьте его ещё раз.

{/* Скриншот: /images/school-bot/04-token-tested.png — блок «Настройка»: выбран «Свой бот», токен проверен */}

После сохранения бот школы сразу включается: с ближайшей рассылки напоминания идут через него, а у варианта "Свой бот" появляется бейдж "Работает" с названием, аватаром и ссылкой на бота.

{/* Скриншот: /images/school-bot/05-connected.png — блок «Настройка» с подключённым ботом школы */}

Если "Тест" не прошёл, под полем появится причина:

| Сообщение                               | Что делать                                                                         |
| --------------------------------------- | ---------------------------------------------------------------------------------- |
| "MAX не принял токен"                   | Скопируйте токен заново — целиком, без пробелов в начале и в конце.                |
| "Не удалось связаться с MAX"            | Повторите через пару минут.                                                        |
| "Это бот ЕДУДА"                         | Вставлен токен бота ЕДУДА. Подключите бота своей школы.                            |
| "Этот бот уже подключён к другой школе" | Один бот работает только с одной школой. Создайте для своей школы отдельного бота. |
| "У бота нет публичного имени"           | Проверьте поле "Никнейм" в карточке бота на платформе MAX.                         |

### Шаг 5. Пригласите родителей в бота школы

Родители, которые подключались к боту ЕДУДА, в бота школы сами не переходят. Пока родитель не подключится к боту школы, напоминания ему не приходят.

1. Отправьте родителям ссылку на бота школы — она есть в блоке "Настройка" под названием бота.
2. Родитель открывает чат с ботом и запускает его. Бот присылает приветствие с кнопкой "📱 Отправить номер" — родитель нажимает её.
3. Бот находит детей по номеру телефона и присылает сообщение со списком детей, их расписанием и ссылкой на личный кабинет.

Кто уже подключился, видно на той же странице "Боты": блок "Как идут напоминания", вкладка "Родители".

Что важно:

- Номер телефона в карточке родителя должен совпадать с номером в MAX — иначе бот никого не найдёт.
- Бот школы находит только родителей своей школы.

### Переключение между ботами

В блоке "Настройка" выбранный вариант — это решение школы, а бейдж "Работает" показывает, какой бот пишет родителям на самом деле.

- **Вернуться на бота ЕДУДА.** Выберите "Бот по умолчанию" и подтвердите. Бот школы не удаляется, а выключается: токен сохраняется.
- **Снова включить бота школы.** Выберите "Свой бот" и подтвердите. Токен вводить заново не нужно.
- После переключения напоминания получают только родители, подключённые к выбранному боту. Остальным нужно подключиться к нему — см. шаг 5.
- Пока бот школы выключен, он не отвечает родителям и не открывает кабинет из чата.

### Важные ограничения

- Один бот — одна школа.
- Бот должен работать только с ЕДУДА: ЕДУДА сама настраивает, куда бот присылает сообщения родителей, и задаёт его меню команд. Другой сервис на том же боте будет с ней конфликтовать.
- Заменить токен уже сохранённого бота в интерфейсе пока нельзя.
- Выбирать бота и подключать своего может только владелец школы.

### Мини-FAQ

**После переключения на бота школы родитель перестал получать напоминания. Почему?**  
Он подключался к боту ЕДУДА. Пусть откроет бота школы и нажмёт "Отправить номер".

**Бот отвечает "По этому номеру я никого не нашёл".**  
В карточке родителя записан другой номер. Исправьте номер в карточке ученика, в блоке "Родители", и попросите родителя нажать кнопку ещё раз.

**Кнопка кабинета в чате с ботом не открывает кабинет.**  
Проверьте адрес мини-приложения в настройках бота на платформе MAX — см. шаг 2.

**Можно ли подключить бота, пока он на модерации?**  
Нет. Токен понадобится после статуса "Опубликован".

**Что будет с напоминаниями, пока я настраиваю бота школы?**  
Ничего не прервётся: до нажатия "Сохранить" напоминания отправляет бот ЕДУДА.
